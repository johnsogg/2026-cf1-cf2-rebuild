# Color

> - Colors have standard names - see
>   https://www.w3.org/TR/css-color-4/#named-colors for the standard used by
>   p5.js
> - Colors can also be built with components:
>   - One number = grayscale
>   - Three numbers = mode-dependent, by default red, green, blue
>   - Four numbers = mode dependent, by default red, green, blue, alpha
