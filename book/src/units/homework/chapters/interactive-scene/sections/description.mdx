# Interactive Scene

Last time we made a still life - a self portrait, possibly. This time, we're
breathing life into your code and making it interactive. The goal here is to
capture mouse and keyboard activity and react to it in some interesting way.

## What to do

Create an interactive scene, such as a 'self portrait' like last time, or any
other scene you can think of (and build in code), but augmented to respond to
user input.

{/* prettier-ignore-start */}

See <Link to="/programming-languages/javascript/interactivity">Interactivity</Link>
for more about how user input can be captured and handled. That section has a 
silly example of an interactive face, which would fit the bill for this 
assignment exactly.

{/* prettier-ignore-end */}

## Where to do it

Like last time, you should use the p5 web editor at
[editor.p5js.org/](https://editor.p5js.org/) to write code. Remember to give
your sketch a reasonable name so you can find it.

## How to turn it in

Just like last time. Use `File -> Share` to open the share dialog. Copy the
option that supports editing. Then paste that URL into the text box in Canvas
for the assignment.

## Rubric

**Include the following in your sketch**

- Canvas should not be huge (mine was 150 square) - at most 500px in each
  dimension
- A background color
- It should render a still scene of some sort (self portrait, a building, car,
  etc).
- Capture user input in each of the following ways, in the appropriate places:
  - Reference variables like `mouseX` or `key`
  - Write and use callback functions like `mouseMoved`
  - Use utility functions like `keyIsDown`
- Each type of user input should visually reflect a change in your erstwhile
  still scene, thereby making it interactive.
