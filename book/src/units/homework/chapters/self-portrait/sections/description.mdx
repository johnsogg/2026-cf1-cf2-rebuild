This assignment gives you practice in creating static art. The example above is
a gallery of the self portraits made by the students in my Fall 2025 CF1 class.
They did this after one week of learning to code.

## What to do

Create a 'self portrait' using lines, squares, rectangles, circles, ellipses,
paths. As you can see from the above, you have a lot of latitude in what
constitutes a self portrait. Have fun with this!

See <Link to="/programming-languages/javascript/p5-graphics">p5 Graphics</Link>
for more on shapes, styles, and color.

## Where to do it

The editors in this book don't (as of this writing) support saving or sharing
anything. So for that, we'll use p5js.org. Make an account on
[p5js.org](https://p5js.org/). I recommend you make a Github account and use
that to sign in to p5js.org - later on you'll use Github often, so that is a
good investment.

Use [editor.p5js.org/](https://editor.p5js.org/) to write code. Be sure to save
it and give it a good name. You'll make a hundred sketches this semester, so a
naming convention that is searchable will help!

## How to turn it in

Having saved your p5js.org sketch, then use `File -> Share` to open the share
dialog. Copy the option that supports editing. Don't worry, nobody can edit
_your_ code, but this lets people make a copy of it. The share URL will look
something like
[https://editor.p5js.org/johnsogg/sketches/T-fxxEhnp](https://editor.p5js.org/johnsogg/sketches/T-fxxEhnp).

Then paste that URL into the text box in Canvas for the assignment.

## Rubric

The most important thing is that you focus on using code as a creative outlet.
We can't grade that because we can't read your mind. So in lieu of that, here is
a punchlist to try to hit.

**Include the following in your sketch**

- A background color
- Three of the following shape types:
  - Line
  - Circle
  - Ellipse
  - Square
  - Rectangle
  - Path
  - Polygon (what p5 calls a Shape)
  - Text
- A shape with fill but no stroke
- A shape with stroke but no fill
- At least five different colors
- At least one use of color mode or rect mode
