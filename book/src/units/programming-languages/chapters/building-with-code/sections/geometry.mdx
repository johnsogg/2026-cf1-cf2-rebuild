> Simple spatial math for making things interact with space. Goals:
>
> - dist(x1, y1, x2, y2) — distance between two points
> - Point-in-circle test: dist(px, py, cx, cy) < radius
> - Point-in-rectangle test: axis-aligned bounding box check (px gte rx && px
>   lte rx+rw && py gte ry && py lte ry+rh)
> - Line/line intersection: the math and a reusable function for it
> - Angle between two points: atan2(dy, dx)
> - Connecting geometry to interactivity: "did the user click on this shape?" is
>   a geometry question These are the building blocks of hit-testing, collision
>   detection, and spatial queries. Students don't need to derive the formulas
>   from scratch — they need to know what tools exist, what they do, and how to
>   reach for them. The AABB check previews the data structures chapter.
