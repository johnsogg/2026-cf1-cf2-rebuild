# Objects

In programming languages, an object is a structure that groups data together.
You could have an object representing a person, so you'd need things like their
first name, last name, home address, social security number, job title, date of
birth, favorite music, ... whatever you need! Objects are a powerful way to
design with code.

## Object literals

In JavaScript, an object is defined with curlies, and lets you define as many
'properties' as you like, separated by commas. Each property has a name, then a
colon, then a value.

> Grouping related values under a single name. Goals:
>
> - Object literals: `{ x: 10, y: 20, radius: 5, color: 'red' }`
> - Reading and writing properties with dot notation
> - Passing objects to functions
> - Arrays of objects (natural bridge to the Lists section)
> - Why objects help: instead of parallel arrays (xs[], ys[], radii[]), one
>   array of objects keeps related data together This section stays at the level
>   of plain data objects (no classes yet). The motivating example is a "thing"
>   in the sketch — a ball, a particle, a character — that has multiple
>   properties that need to travel together. Classes and constructors are out of
>   scope here; the concept is "a bundle of named values."
