## Glossary Terms

You can use `<Term>xyz</Term>` to add a word like <Term>recursion</Term> to the
glossary. If it is not present, it renders with a dumb style to make it obvious
that you should add it, like <Term>garbanzo</Term>.

## Inline p5 Sketches

This 'component' is actually a kinda complex Vite + Remark exploit that lets me
write a p5.js sketch directly in the `.mdx` file. This is convenient because it
has zero dependencies. But it is limited for the same reason. This is good for
short examples but maxes out quickly.

```p5sketch autoplay width=300 height=100
function setup() {
  createCanvas(300, 100);
}

function draw() {
  background(192);
  stroke("#111")
  line(20, 20, 280, 80)
  fill("#444")
  circle(width/2, height/2, 80)
}
```

## Ask / Solution

`<Ask id="..." mode="untracked" | "interacted" | "graded">` wraps any
content — prose, a sketch, an editor, a mixture — and owns whether/how it
counts toward book progress, independent of what's rendered inside.
`<Solution id="...">` pairs with an `Ask` by reusing its id, not a second
one. Responses persist to local storage and roll up into overall student
progress.

### `graded` — real correctness signal

Only `CodeExercise` (unit tests) and `MultipleChoiceExercise` (right
answer) can supply this. State goes idle → attempted (partial credit) →
complete.

<Ask
  id={greetAndSquare.id}
  mode="graded"
  title={greetAndSquare.title}
  hints={greetAndSquare.hints}
>
  <CodeExercise exercise={greetAndSquare} />
</Ask>

<Solution id={greetAndSquare.id}>

One way to do it: `` return `Hello ${name}` `` and `return n * n`.

</Solution>

<Ask
  id={typeAnnotationQuestion.id}
  mode="graded"
  title={typeAnnotationQuestion.title}
  hints={typeAnnotationQuestion.hints}
>
  <MultipleChoiceExercise exercise={typeAnnotationQuestion} />
</Ask>

### `graded` with nothing gradable inside

`P5Exercise`/`ConsoleExercise` never report a grade — wrapping one in
`mode="graded"` triggers a live warning banner right here in the page,
not just a build-time console message.

<Ask id="compendium-graded-mismatch" mode="graded" title="This will warn">

```p5exercise size="small" autorun
function setup() {
  createCanvas(120, 120)
}

function draw() {
  background("black")
}
```

</Ask>

plain prose with no widget at all.

## Expected Read Time indicator

There's an `<ExpectedReadTime wordCount={wordCount}>` component that tells you
roughly how long it will take to read. It has to be written exactly like this
because (I think) the Vite transformation inserts the variable `wordCount` into
the page, so it is a just-in-time resolved symbol. That's what puts the `3 min`
or whatever into the bottom right corner.

<ExpectedReadTime wordCount={wordCount} />
